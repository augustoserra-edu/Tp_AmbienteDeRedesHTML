Declaraciones en bloque definidas entre etiquetas style

h1 {
    font-size: 2em;
    color: darkblue;
    text-align: center;
    background-color: aquamarine;
}

Todos los textos con etiquetas h1 tienen este estilo.

La etiqueta h1 ocupa todo el ancho del contenedor (por defecto tiene display de bloque).

La etiqueta h1 lleva texto en color azul.

El fondo de un h1 lleva color aquamarine.

El estilo definido para la etiqueta h1 indica que el texto irá centrado.

p {
    font-size: 1em;
    text-align: left;
    color: blue;
    font-style: italic;
    border-top: thin solid blue;
    border-bottom: thin solid blue;
}

Todos los textos con etiquetas p tienen este estilo definido dentro de la etiqueta style.

Para los párrafos se define una alineación a la izquierda.

Tamaño de letra de la misma medida que la definida para el contenedor body.

Color de letra azul.

Estilo de la fuente itálico.

Bordes superior e inferior sólidos, finos y de color azul.
