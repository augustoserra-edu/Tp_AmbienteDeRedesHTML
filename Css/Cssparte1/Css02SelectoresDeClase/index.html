Selectores de clase

A partir de esta página no usaremos el atributo style en ninguna etiqueta.

Todo el estilo de este ejercicio se define dentro de una etiqueta style en el head del documento.

p { /* Estilo por defecto para cualquier párrafo */
    font-size: 1em;
    margin-bottom: 60px;
}

Los párrafos incluyen un margin-bottom para separarlos entre sí.

.claseResaltado {
    font-size: 1em;
    font-weight: bold;
    background-color: yellow;
}

Este párrafo toma el estilo definido en el encabezado del documento como class="claseAcotacion".

Este párrafo toma el estilo definido como class="claseResaltado".

Este párrafo toma el estilo definido como class="claseAyuda".

Este párrafo toma el estilo definido como class="claseContenidoComun".

Párrafo con un estilo particular para el identificador id="idUnico". El selector de identificador utiliza el símbolo #.

Las imágenes con class="imagenAl50" ocupan el 50% del ancho del contenedor, independientemente de su tamaño original.
