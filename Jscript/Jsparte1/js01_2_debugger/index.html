El siguiente código será ejecutado a continuación:

let a = 4;
let b = 6;
let c = a + b;
console.log('Valor de la variable c: ' + c);

Abrí las herramientas del navegador con F12 y visualizá el resultado en la consola.

Podés colocar un punto de interrupción en el archivo ejercicio.js para observar las variables paso a paso.
